SBI FD Calculator - Installable PWA
1. Upload ALL files in this folder together to a secure HTTPS static hosting service (e.g. GitHub Pages or Netlify).
2. On Android open the hosted URL in Chrome.
3. Chrome menu > Add to Home screen > Install (wording varies).
4. Open from your home screen. Once loaded, the calculator can work offline.
Opening index.html from Downloads will NOT enable PWA installation/service worker.
Reference rates are user-supplied, not verified current SBI rates.
